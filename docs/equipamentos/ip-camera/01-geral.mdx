# IP Camera

A **IP Camera** possui um site próprio para acessar e configurar a câmera através do navegador.

Para acessar, basta digitar o endereço IP da câmera na barra de endereço, por exemplo:

`http://192.168.0.123/index.html`

Após fazer o login, é possível visualizar a câmera e acessar suas configurações, como imagem, vídeo, rede e controle da câmera.

Nesta seção, serão explicadas as opções de cada aba do site.
