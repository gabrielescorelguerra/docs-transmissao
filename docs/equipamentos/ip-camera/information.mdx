## Informações do dispositivo

Esta área apresenta informações sobre a câmera, seu modelo e as versões dos programas instalados.

### Device Name

É o **nome da câmera**.

Pode aparecer um nome definido pelo fabricante ou um nome personalizado para facilitar a identificação do equipamento.

### Device Model

Indica o **modelo da câmera**.

Esse valor identifica qual é o modelo físico do equipamento e pode ser utilizado para consultar suas características e compatibilidade.

### Device Serial

É o **número de série** da câmera.

Cada equipamento possui um número próprio, utilizado para identificar aquela câmera especificamente.

### Software Version

Indica a **versão do software interno da câmera**.

Normalmente aparece no formato de uma versão seguida da data ou número da compilação, por exemplo:

`1.00 Build20240716`

A primeira parte indica a versão do software, enquanto o **Build** identifica a compilação específica utilizada.

### Web Version

Indica a **versão da interface web** da câmera, ou seja, a versão do sistema que apresenta as páginas de configuração acessadas pelo navegador.

Pode aparecer, por exemplo:

`1.00`

### AF Version

Indica a **versão do sistema de foco automático (AF)** da câmera.

Esse valor pode variar conforme a versão do sistema de foco instalada no equipamento.
