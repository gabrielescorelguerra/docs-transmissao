# Exibindo o nome do ministro

Deixe a fonte **"Nome do ministro"** visível e clique em **Esmaecer** para exibir o nome na transmissão.

Depois, ative o **widget do nome do ministro** para mostrar o nome na parte inferior da tela, conforme mostrado no vídeo.

<YouTubeVideo id="YlywceRgU6c"/>

Quando o nome desaparecer da transmissão, **desative o widget do nome do ministro**, clicando no mesmo botão que foi clicado para mostrá-lo.
